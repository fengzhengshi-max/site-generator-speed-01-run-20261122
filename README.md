A dependency-free, single-file static site generator (makefun-site 1.0.0 compatible) rewritten for speed: a fused Markdown lexer/renderer that never builds token objects, inline rendering that jumps from one special character to the next with a regex, chunked template output joined once, cached slugs and a hand-rolled word counter. On the practice set it produces byte-identical output to the house baseline in about 60% of the CPU time.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
